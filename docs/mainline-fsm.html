States and mode boxes

Each state names the focused surface and trip phase. Empty/valid input and unselected/selected choice are substates because their available commands differ. Voice is above pointer interaction in the reset view.

Lifecycle, scheduling, intervals, editors, goal modes, Sync, microphone and persistence have separate boxes. Their depth separates branches; changing the camera does not change the FSM.

T is the captured trip phase; P is the return surface; F is the field being edited. These are explicit state families. Instantiate their captured values in each test; never treat every return as Running.

Commands and speech

Commands are underneath each state, highest interruption/continuation priority first. Availability remains conditional on the actual focus, valid input, permissions, connection and recognizer state.

A fully formed continuation owns its prefix before shorter conflicting commands. The list does not introduce a new global numeric priority scheme. Cancel/Close resolves the actual top surface; Off/Sleep applies only when recognition permits it.

Skippable feedback is omitted when the same utterance continues into another valid command. B01–B04 are skippable, so “start break lunch ok” announces the final outcome. UI actions still execute immediately. Click the small + box on a double line to expand its chime / summary / details table and suppression footer; − collapses it. Click the line to inspect its full details. Audio rows follow playback order, from top to bottom. Optional components use ◇; queue priority and suppression exceptions are in the footer. Select “All labels / tables” to show every visible voice table. Chime note names are in the inspector.
