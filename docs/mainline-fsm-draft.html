States and mode boxes

Each state names the focused surface and trip phase. Empty/valid input and unselected/selected choice are substates because their available commands differ. Voice is above pointer interaction in the reset view.

Lifecycle, scheduling, intervals, editors, goal modes, Sync, microphone and persistence have separate boxes. Their depth separates branches; changing the camera does not change the FSM.

T is the captured trip phase; P is the return surface; F is the field being edited. These are explicit state families. Instantiate their captured values in each test; never treat every return as Running.

Commands and speech

Commands are underneath each state, highest interruption/continuation priority first. Availability remains conditional on the actual focus, valid input, permissions, connection and recognizer state.

A fully formed continuation owns its prefix before shorter conflicting commands. The list does not introduce a new global numeric priority scheme. Cancel/Close resolves the actual top surface; Off/Sleep applies only when recognition permits it.

Skippable feedback is omitted when the same utterance continues into another valid command. B01–B04 are skippable, so “start break lunch ok” announces the final outcome. UI actions still execute immediately. Click the small + box on a double line to expand its chime / summary / details table and suppression footer; − collapses it. Click the line to inspect its full details. Audio rows follow playback order, from top to bottom. Optional components use ◇; queue priority and suppression exceptions are in the footer. Select “All labels / tables” to show every visible voice table. Chime note names are in the inspector.

        Behavior contracts

        UI: Apply optimistic outcome immediately. Commands that are client-only do not access remote persistence.

        server: For commands requiring persistence, validate before any write. Rejection restores the checkpoint and cancels dependent operations.

        retry: Local transient storage failures retain optimistic UI and retry asynchronously with 150 ms exponential delay capped at 2000 ms. Abort ends retries. Remote-write retry/idempotency contract remains unresolved.

        time: Durations and boundaries are milliseconds; absolute dates are timezone-aware. Finishing and confirming a new trip are separate user actions, not an automatic continuous boundary.

        summary: Trip Summary can be requested at any time and speaks totals for every trip in selected range except current active trip. No data renders/speaks No trip data available. Both paths hold until OK/Cancel. trip-ended/system adds Say OK to start a new trip LAST; requested/voice or pointer suppresses that prompt and returns to prior focus on OK/Cancel. Range refresh preserves invocation.

        voicepad: Voicepad access while disabled requests explicit recognition enable. OK enables recognition before opening; Cancel preserves current surface. Sleep/off while editing automatically preserves value and opens keypad.

        settings: Settings focus coexists with trip/clock/range regions. Closing settings restores prior focus; persistence rejection restores state and dependent changes.

        locale: Semantic state/range IDs remain stable. UI text, spoken command vocabulary, recognition patterns and announcement templates belong to the selected language pack.

        aggregation: TripAggregates shared calculations: latest row wins per String(id); anonymous rows remain distinct. Range bounds inclusive from CalendarRange.tripWindow. Counted time uses persisted counted milliseconds, fallback actual; active trip counted=max(allotted,counted). percent=standard/counted (null at zero); banked=round(standard/goalPercent-counted). Summary includes both production/nonproduction, excludes running/current ID. Log keeps its production filter and existing active-trip inclusion rule. Results are immutable state.tripAggregates children, UI invocation stays state.tripSummary.

        Suppression rule register

        AUD-USER: That audio layer or announcement component is user-disabled; consumeAnnouncementAction / per-layer settings

        AUD-CONT: Component is skippable and continuation exists; speech-skippable + hasContinuation()

        AUD-RANGE: changeGoalMode receives a localized range command; setTripLogRange(announce:false), then one range-change announcement; feedback adapter excludes range commands

        AUD-CANCEL: Command loses permission to commit or its transaction rejects; Command cancellation / transaction rollback / semantic queue guard

        AUD-STALE: Surface ownership changed before playback; Current-surface speech guard

        AUD-FALLBACK: Sleep/off causes automatic voicepad-to-keypad transition; reconcileVoicePadRecognition; voiceCommandFeedback skips its duplicate when the source was voicepad

        AUD-SUMMARY-PROMPT: reason == requested; trip-ended retains prompt last; tripSummary.invocation.reason conditional
